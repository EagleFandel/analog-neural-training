## 摘要
在算力与能耗矛盾突出的背景下，本文提出并系统论证一种“模拟计算启发的神经网络训练”范式：以连续时间动力系统为统一视角，构建由RK4、DOPRI54、IMEX与辛积分等方法组成的优化器体系，辅以数字/模拟/混合能耗模型，实现对准确率、收敛速度与能效的综合优化。工程层面，基于开源工具链构建完整实验体系（含基准数据、可视化与报告导出），并在MNIST子集、正弦回归、刚性问题与强化学习等情境开展对比评测。结果表明：DOPRI54在能效—精度权衡中表现优异，辛积分在长期训练下能量漂移低且稳定性更好，IMEX在刚性场景允许更大有效步长；教育实践显示“能耗意识+连续时间”教学设计对学习成效与工程素养具有积极作用。本文提供可复现的图表生成流程与数据来源说明，便于审查与推广。

## 一、课题由来
随着深度学习应用的普及，训练过程的时间与能耗逐渐成为问题。在校内社团与课程实践中，常见优化方法的“步长—误差—能耗”关系并不直观，且在边缘设备或受限环境下易出现“训练慢或不稳定”的现象。为此，本文尝试以连续时间动力系统统一刻画训练过程，并引入适于长期稳定与能效优化的数值方法（如辛积分、自适应步长与IMEX），以期在保证精度的同时降低能耗、提升稳定性与复现性。

## 二、研究目的
- 在统一框架下比较多种优化器（RK4、DOPRI54、IMEX、辛积分）的收敛、稳定性与能效；
- 构建可复现的数据—图表—报告产线，提升结果的可核查性与可分享性；
- 探索在受限场景（如边缘设备、刚性问题）下的实用策略；
- 形成适合高中学习者的“能耗意识+连续时间”学习范式，提升工程素养与科学探究能力。

## 三、研究方法与过程
### 3.1 整体方法
以连续时间动力系统为统一视角，构建优化器族：
- RK4：固定步长，四阶精度，适合平滑损失；
- DOPRI54：自适应步长控制，目标是在既定误差容限下减少函数评估次数（NFE）；
- IMEX：将刚性项隐式处理以扩大稳定域，适合强正则与刚性问题；
- 辛积分：在动量/哈密顿结构下保持能量性质，长期训练更稳定。

### 3.2 指标与能耗建模
- 指标：NFE、时间、相对能耗、准确率、能量漂移；
- 能耗建模：数字/模拟/混合三类模型，分别从FLOPs/访存与电容/ADC-DAC能耗角度估算；
- 数据来源：`results/benchmark_results.json`、`results/summary_energy.csv`、`results/symplectic_vs_rk.csv`、`results/imex_vs_rk.csv` 等。

### 3.3 实验过程
- 基准测试：执行 `experiments/benchmark_suite.py --all --steps 100`，生成基准曲线与表格；
- 应用案例：运行 `examples/use_cases/` 中IoT传感器、手机端微调、强化学习、刚性优化四个脚本；
- 图表导出：以代码先导出PNG，再嵌入文档或PDF，确保评审可直接查看。

### 3.4 过程控制与匿名
- 随机性控制：使用固定随机种子 `set_global_seed`；
- 合规：不出现学校、个人与教师信息；仅展示统计结果与工程图表。

### 3.5 核心代码示例 (匿名)
```python
# 1. 创建模型与优化器
from src.models.mlp import MLP
from src.optim.analog_inspired import create_optimizer

# 创建简单模型 (输入10维, 隐藏层16, 输出2类)
model = MLP([10, 16, 2])

# 创建DOPRI54自适应优化器
optimizer = create_optimizer(
    "dopri54",
    model.loss_and_grad, # 损失与梯度函数
    model.theta0,        # 初始参数
    lr=1e-3
)

# 2. 训练循环
for step in range(50):
    # 执行一步更新
    theta, loss = optimizer.step(x_train, y_train, "classification")
    if step % 10 == 0:
        print(f"步骤 {step}: 损失={loss:.4f}")
```

## 四、研究结果
### 4.1 基准与收敛
如图1所示（数据源: `results/benchmark_results.json`），不同优化器在损失函数下降过程（Loss—Steps）中表现出不同特性。DOPRI54的收敛曲线在前期下降更快且最终损失更低，显示出更高的收敛效率。

### 4.2 能效与Pareto
如图2所示（数据源: `results/summary_energy.csv`），DOPRI54与IMEX方法在相同的能耗水平下取得了更高的准确率，在准确率—能耗的Pareto前沿上占据优势地位。

### 4.3 长期稳定性
如图3所示（数据源: `results/symplectic_vs_rk.csv`），辛积分方法的能量漂移始终维持在较低水平，而RK4则随时间累积误差，验证了辛积分的保结构优势，使其更适合长期训练任务。

### 4.4 刚性优化
如图4所示（数据源: `results/imex_vs_rk.csv`），IMEX方法在刚性问题中能够承受比RK4更大的步长而保持稳定，避免了数值发散，展现出处理此类问题的优越性。

### 4.5 强化学习案例
如图5所示（数据源: `results/figures/rl_symplectic_vs_rk4.png`），在倒立摆控制任务中，尽管最终回报相近，但辛积分方法的能量函数更为平滑，有利于策略的稳定学习和长期表现。

## 五、结论和分析
- 统一的连续时间训练框架便于比较不同优化器；
- DOPRI54在能效—精度权衡上表现更优；
- 辛积分长期训练更稳定，能量漂移低；
- IMEX在刚性问题中允许更大有效步长并抑制发散。

局限性：数据集规模与多样性有待扩展；能耗模型仍需硬件在环验证；样本与场景有限，需更多重复实验支持。后续工作将聚焦：（1）更大数据集与更多模型；（2）硬件在环测试与能耗实测；（3）完善教学任务与量表，开展更大样本的验证。
