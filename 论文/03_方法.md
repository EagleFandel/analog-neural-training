# 3 方法

## 3.1 优化器族（连续时间视角）
设损失函数为\(L(\theta)\)，基本梯度流为\(\frac{d\theta}{dt} = -\nabla L(\theta)\)。在此基础上，我们构建以下积分/优化方法族：
- RK4（四阶龙格-库塔）：以固定步长提供高精度更新，适合平滑损失与中等步长；
- DOPRI54（Dormand–Prince 5(4)）：自适应步长控制，目标是以较少NFE达到既定误差阈值；
- IMEX（隐显式）：针对刚性问题，将刚性项隐式处理以扩展稳定域；
- Symplectic（辛积分）：在动量/哈密顿结构下保持能量性质，适合长期训练稳定性；
- SDE优化：通过噪声项\(d\theta = -\nabla L(\theta)\,dt + \sigma\,dW_t\)提升鲁棒性，对低精度硬件/随机扰动环境更友好。

步长策略：RK4和Symplectic采用固定或分段常量步长；DOPRI54依据局部截断误差自适应调整；IMEX对刚性项采用隐式子步。

### 3.1.1 统一伪代码（示意）
```python
# 伪代码：统一连续时间优化接口
state = initialize(theta0)
for step in range(T):
    if method == 'dopri54':
        h = adapt_step(local_error, tol)
    elif method == 'imex':
        theta = implicit_update(theta, stiff_term, h)
    elif method == 'symplectic':
        theta, momentum = symplectic_step(theta, momentum, h, gamma)
    else:  # rk4 or others
        theta = rk4_step(theta, grad, h)
    record(loss(theta), nfe, time, energy_proxy(theta))
```

稳定性与收敛：在PL条件下可得到指数型收敛界；在Lyapunov框架下比较不同积分器的稳定区间与能量性质（Karimi et al., 2016；Hairer et al., 2006）。

## 3.2 能耗建模与硬件仿真
### 3.2.1 能耗模型
- DigitalEnergyModel：\(E_{dig} = \alpha_1\cdot\text{FLOPs} + \alpha_2\cdot\text{MemAccess} + \alpha_3\cdot t\)；
- AnalogEnergyModel：\(E_{ana} = \beta_1\cdot C\Delta V^2 + \beta_2\cdot I_g V t + \beta_3\cdot E_{ADC/DAC} + \beta_4\cdot E_{leak}\)；
- HybridEnergyModel：\(E_{hyb} = \lambda E_{ana} + (1-\lambda)E_{dig}\)。

### 3.2.2 噪声与量化
- 量化：\(x_q = \text{round}(x/\Delta)\cdot \Delta\)，位宽b决定\(\Delta\)；
- 噪声：高斯热噪声\(\eta\sim\mathcal{N}(0,\sigma^2)\)，注入到前向或梯度；
- SDE鲁棒：通过随机扰动模拟低精度与传感噪声环境。

### 3.2.3 指标与记录
- NFE、时间、能耗（相对/绝对）、准确率、能量漂移；
- 准确率—能耗Pareto；
- 数据来源：`results/*.csv|*.json`。

## 3.3 教育研究设计
### 3.3.1 研究对象与分组
- 场景：课程/社团/实训；对照组（常规教学）vs 干预组（连续时间+能耗意识+可视化）。

### 3.3.2 指标体系与量表
- 概念测验（信度Cronbach's α>0.7）；
- 任务完成度（Rubric多维评分：正确性、复现性、图表质量、论证严谨性）；
- 自评与学习投入（Likert 1–5）；
- 工程素养：是否能基于数据作出“步长—误差—能耗”的合理选择。

### 3.3.3 统计分析
- 显著性检验：配对t检验/独立样本t检验（正态性不满足用Mann–Whitney）；
- 效应量：Cohen's d；
- 置信区间：95%；
- 缺失值：列表删除或多重插补（样本量允许时）。
